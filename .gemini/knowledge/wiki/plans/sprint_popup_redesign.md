## 1. 스프린트 목표

확장 프로그램 팝업을 흰색 기반과 제공 아이콘의 하늘색 포인트를 사용하는 간결한 설정 화면으로 리디자인한다. 사용자는 확대 기능을 켜고 끄며 `90 × 90`(기본) 또는 `120 × 120` 미리보기 크기를 선택하고, 하단 링크로 수땡 방송을 바로 열 수 있다.

## 2. UI 계약

- 배경은 밝은 흰색 계열, 포인트는 아이콘의 하늘색 계열을 사용한다.
- 헤더에는 제공 아이콘, `커져라! Hugify!` 이름, ON/OFF 상태만 둔다.
- 설명 문장과 버전 표기는 제거하고, 설정 카드는 확대 토글과 크기 선택에 집중한다.
- 크기 선택은 두 개의 카드형 옵션으로 제공하며 `90 × 90`을 기본 선택한다.
- 하단에는 아이콘과 함께 `수땡 방송 바로가기` 링크를 제공한다.
- 확장 기능의 저장 설정은 `enabled`, `size`만 사용한다. 기존 부가 설정은 다시 노출하지 않는다.

## 3. 완료 기준

- [x] 팝업이 밝은 테마와 파란 포인트로 표시되고 불필요한 문구가 제거된다.
- [x] 제공 아이콘이 헤더에 표시된다.
- [x] `90 × 90`이 기본 선택되고 `120 × 120`으로 변경/저장된다.
- [x] content script가 저장된 크기로 툴팁 이미지와 위치를 계산한다.
- [x] 수땡 방송 링크가 새 탭으로 열린다.
- [x] 기존 이모티콘 확대/활성화 동작과 전체 테스트가 유지된다.
- [x] README, 위키 인덱스, 감사 로그가 현재 UI와 일치한다.
