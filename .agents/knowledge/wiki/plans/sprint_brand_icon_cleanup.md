# SC-20260920-08: Hugify 브랜딩 및 아이콘 교체

> **계약 ID**: SC-20260920-08
> **담당자**: Developer
> **검증자**: Evaluator
> **날짜**: 2026-09-20

---

## 1. 스프린트 목표

사용자가 제공한 이모티콘 이미지를 확장 프로그램 아이콘으로 적용하고, 현재 사용자에게 노출되는 `확대기` 명칭을 `커져라! Hugify!` 브랜딩으로 통일한다.

## 2. 완료 기준

- [x] 제공 이미지가 `16`, `48`, `128` 아이콘 에셋에 적용된다.
- [x] Manifest와 런처의 사용자 노출 명칭에 `확대기`가 남지 않는다.
- [x] 아이콘 PNG의 실제 크기가 manifest 선언 크기와 일치한다.
- [x] 기존 테스트와 브랜딩/아이콘 회귀 테스트가 통과한다.
- [x] 변경 사항과 검증 결과가 위키 로그에 기록된다.

## 3. 영향 범위

| 파일 경로 | 변경 목적 |
|---|---|
| `icons/icon16.png` | 제공 이미지의 16 아이콘 |
| `icons/icon48.png` | 제공 이미지의 48 아이콘 |
| `icons/icon128.png` | 제공 이미지의 128 아이콘 |
| `manifest.json` | 확장 프로그램 표시 이름 및 설명 변경 |
| `package.json` | 프로젝트 설명 브랜딩 정리 |
| `scripts/launcher.js` | CLI 도움말 표시 이름 변경 |
| `tests/branding.test.js` | 브랜딩 및 PNG 크기 회귀 검증 |
